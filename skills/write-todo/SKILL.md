# 写 / 更新 todo.md

## 写入边界

- 只处理当前正在进行的任务；新任务追加新条目。
- 不使用 `cp`、`mv`、`rm` 等可能覆盖、删除或清空文件的命令操作 `.codex/todo.md`。
- 不删除、覆盖、清空内容，也不修改其他任务（含已完成任务）的记录；清理由用户决定。
- `.codex/` 是本地工作流目录；除非用户明确要求，不纳入 Git 提交。

## 开始前

- 读取现有 `.codex/todo.md`，并核对当前 Plan、用户最新指令、Git 状态和与任务相关的文件或运行记录。
- 文件不存在时创建新条目；文件已存在时保留全部既有记录，只处理当前任务。

## 记录内容

- 当前活动任务至少包含：目标与验收标准、状态、已完成与剩余工作、唯一下一动作、关键决策与假设、证据及产物路径、阻塞、已证伪路径、工作区或提交状态。

## 条目结构

- 新条目沿用现有文件的风格；没有现有文件时，从 `## 任务：<名称>` 开始，并依次记录状态、更新时间、目标与验收标准、已完成、剩余、下一动作、关键决策与假设、证据与产物、阻塞、已证伪路径、工作区或提交状态。

## 失败路径记录

- 记录失败证据或原因、适用范围和允许重试的条件；证据注明来源或路径，不写无法核验的结论。

## 充分性检查

- 写入后确认：一个不了解先前对话的新 Agent 结合 Memory 和当前工作区，能回答目标、已完成、剩余、下一步、为什么以及哪些路径不能再试。

## 完成后

- 将当前任务标记为已完成，并记录验证、提交、剩余风险和简短复盘。
- 报告新增或更新的记录位置；记录本身不提交到 Git。
