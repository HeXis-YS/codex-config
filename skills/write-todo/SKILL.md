# 写 / 更新 todo.md

## 开始前

- 读取现有 `.codex/todo.md`；文件不存在时创建新条目，文件已存在时保留全部既有记录，只处理当前任务。
- 新条目沿用现有文件风格；没有现有文件时，从 `## 任务：<名称>` 开始。

## 条目结构

使用 Markdown task list 表达状态：

```markdown
## 任务：<名称>

状态：<进行中 / 已完成>
更新时间：<YYYY-MM-DD>

- [x] 已完成：...
- [ ] 待办：...
- [ ] 唯一下一步：...
```

- 已完成项和待办项使用 `- [x]` / `- [ ]`；唯一下一步使用单独的一个 `- [ ]` 条目，待办可以有多个，但唯一下一步只有一个。
- 关键决策与假设、证据与产物、阻塞、已证伪路径、工作区或提交状态作为普通字段记录，不使用 checkbox。

## 记录细节

- 记录失败证据或原因、适用范围和允许重试的条件；证据注明来源或路径，不写无法核验的结论。

## 充分性检查

- 写入后确认：一个不了解先前对话的新 Agent 结合 Memory 和当前工作区，能回答目标、已完成、剩余、下一步、为什么以及哪些路径不能再试。

## 完成后

- 报告新增或更新的记录位置。
